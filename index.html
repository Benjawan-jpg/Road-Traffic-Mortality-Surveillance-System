เชื่อมต่อฐานข้อมูล Google Sheets (Real-Time Pipeline)

วิธีเอาลิงก์จาก Google Sheets ของคุณ:

1. เปิด Google Sheets ของคุณ (ควรมีคอลัมน์เช่น: วันที่, เวลา, จังหวัด, อำเภอ, ละติจูด, ลองจิจูด, เพศ, อายุ, ยานพาหนะ, หมวก/เข็มขัด, สุรา)

2. ไปที่เมนู ไฟล์ (File) > แชร์ (Share) > เผยแพร่ทางเว็บ (Publish to web)

3. เลือก ทั้งเอกสาร (Entire Document) และเปลี่ยนรูปแบบจาก หน้าเว็บ เป็น ค่าที่คั่นด้วยจุลภาค (.csv)

4. กดปุ่ม เผยแพร่ (Publish) แล้วคัดลอกลิงก์ที่ได้มาวางในช่องด้านบน

ปักหมุดผู้เสียชีวิต / จุดเกิดเหตุใหม่

ท่านสามารถพิมพ์พิกัด หรือ คลิกบนแผนที่ เพื่อเลือกพิกัด Lat/Lng โดยอัตโนมัติ

ขั้นตอนการอัปโหลดขึ้น GitHub Pages ให้คนอื่นเข้าดูได้ทั่วโลก

1
บันทึกโค้ดนี้เป็นไฟล์ index.html

คัดลอกซอร์สโค้ดในหน้านี้ทั้งหมดแล้วเซฟชื่อไฟล์ว่า index.html

2
สร้าง Repository ใหม่บน GitHub

ไปที่ github.com/new ตั้งชื่อ Repository เช่น road-safety-dashboard แล้วเลือกเป็น Public

3
อัปโหลดไฟล์ index.html

กดปุ่ม Upload an existing file แล้วลากไฟล์ index.html ใส่ลงไป จากนั้นกด Commit Changes

4
เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings > Pages ใน Repository ของคุณ -> ตรงหัวข้อ Source เลือก Deploy from a branch -> เลือก Branch main (folder /root) -> กด Save

เพียงเท่านี้ Dashboard ของคุณจะออนไลน์ทันทีที่ URL:
https://<username>.github.io/road-safety-dashboard/
